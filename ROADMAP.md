# Roadmap

Reiko's Godzilla Mod is built in five phases. Each phase is playable on its own and adds to the systems before it.

Target: **Minecraft 1.21.1 · NeoForge · GeckoLib 4**

---

## Phase 1: "King of the Monsters" core ✅ (v0.1.0)

The best-known monsters, plus the systems every later monster reuses.

**Monsters**
- [x] Godzilla: Showa (1954–75) and Heisei (1984–95) variants
- [x] King Ghidorah (three independent gravity beams, flight, wing gusts)
- [x] Mothra: larva (silk spray) → cocoon → imago (poison scales, hurricane gusts)
- [x] Rodan (supersonic flight, sonic-boom dive)
- [x] Anguirus (spiked shell, Thunderball roll, tameable and rideable)
- [x] Mechagodzilla, Showa (Space Beam, finger missiles, force field, "Fake Godzilla" disguise)

**Tech and items**
- [x] Type 66 Maser Tank (drivable; unmanned tanks auto-fire at hostile kaiju)
- [x] Oxygen Destroyer (endgame weapon)
- [x] Kaiju drops: G-Cells, Space Titanium, Ghidorah Scales, Mothra Scales, Kaiju Scales

**World**
- [x] Monster Island (volcano, Godzilla, Rodan, Anguirus lairs)
- [x] Infant Island (jungle, shrine, Mothra Egg)
- [x] Kaiju events: Godzilla surfaces offshore, Ghidorah meteor, Mechagodzilla invasion

**Core systems**
- [x] Charged beam attacks (raycast, block damage throttle, rendered beams)
- [x] Flight AI for flying kaiju
- [x] Multipart hitboxes
- [x] Faction AI (Titans / Guardians / Invaders)
- [x] Configurable scale (default 1/5 film size) and anti-grief settings
- [x] Boss bars

**Still to do for Phase 1:** final Blockbench models and textures (stand-ins ship for now), custom sounds.

## Phase 2: Heisei ✅ (v0.2.0)

**Monsters**
- [x] Biollante (Flower Beast and Plant Beast)
- [x] Battra (larva and imago; joins Mothra's side)
- [x] Fire Rodan (Uranium Heat Beam, energy transfer → Godzilla's Red Spiral Ray)
- [x] SpaceGodzilla (Corona Beam, crystal fields, Gravity Tornado, reflecting shield)
- [x] Destoroyah (juveniles → aggregate → flying → Perfect Form, swarm split)
- [x] Baby → Little → Godzilla Junior (hatches from an egg, imprints on a player)
- [x] Burning Godzilla meltdown state (Infinite Heat Ray, Junior absorbs the meltdown)

**Tech**
- [x] Mechagodzilla (G-Force) + Garuda → Super Mechagodzilla
- [x] MOGUERA (splits into Star Falcon and Land Moguera)
- [x] Super X (cadmium missiles), Super X2 (Fire Mirror), Super X3 (freezer weapons)
- [x] DAG-MB96 Freezer Tank
- [x] Piloting: R / V / G weapon keys, piloted flight, over-the-shoulder aiming camera

**New systems**
- [x] Freeze meter and cadmium (weakness system)
- [x] Beam reflection and absorption
- [x] Tameable kaiju base (Anguirus, Junior)
- [x] New events: SpaceGodzilla, Battra, Destoroyah

**Still to do for Phase 2:** final Blockbench models and textures (stand-ins ship for now), custom sounds.

## Phase 3: MonsterVerse ✅ (v0.3.0)

**Titans**
- [x] MonsterVerse Godzilla: Energized (blue), thermonuclear (red) and Evolved (pink) forms, radiation feeding, gill weak point
- [x] Kong (young and adult; Battle Axe, B.E.A.S.T. Glove, climbing, grab and throw)
- [x] MUTOs (male and female, EMP, nests), Skullcrawlers and the Skull Devil, Warbats
- [x] MonsterVerse King Ghidorah (Alpha Call, regrowing heads, storms) plus MonsterVerse Rodan and Mothra
- [x] Scylla, Behemoth, Methuselah, Tiamat
- [x] Apex Mechagodzilla (Proton Scream, Ghidorah takeover)
- [x] Skar King (control crystal), Shimo, Suko, Great Apes

**Tech and world**
- [x] ORCA, HEAV, Nuclear Warhead
- [x] Hollow Earth dimension (three biomes, vortex travel, Kong's throne room, the Skar King's realm)
- [x] Skull Island (storm wall, Skullcrawler caves, Iwi wall, vortex), Tiamat's lair, Antarctic vortex
- [x] New systems: Alpha hierarchy, EMP, frostbite, radiation sources
- [x] New events: MonsterVerse Godzilla, MUTOs, Scylla, Behemoth, Alpha Call, Skullcrawlers

**Still to do for Phase 3:** final Blockbench models and textures (stand-ins ship for now), custom sounds.

## Phase 4: Showa and Millennium deep cuts ✅ (v0.4.0)

**Showa**

- [x] King Caesar (Prism Eye, Shisa Statue awakening), Titanosaurus (implant, Supersonic Wave Oscillator), Mechagodzilla 2

**Millennium**

- [x] Millennian UFO → Orga, Megaguirus with Meganulon and Meganula, the GMK Guardians (Baragon, Mothra, King Ghidorah / Dragon King)
- [x] Kiryu / Kiryu Kai (energy, Absolute Zero Cannon, spirit rampage), Monster X → Keizer Ghidorah, Zilla, Xilien saucers
- [x] Gotengo, Dimension Tide

**Systems and world**

- [x] Sollgel Island, Letchi Island, Godzilla Tower, Seatopia, the Azumi shrine, three GMK shrines, the UFO wreck, Meganulon ruins, Kiryu's hangar, a Xilien mothership; Monster Island residents
- [x] Nine new events

**Still to do for Phase 4:** final Blockbench models and textures (stand-ins ship for now), custom sounds; the Satsuma submarine and the AC-3 White Heron as vehicles.
